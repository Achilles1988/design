## Product purpose

A design step for your engineering workflow — install it into any repo. It manages Apps, blank Canvases, reusable design assets, and AI-assisted authoring on disk, so you can get drafts out fast, tweak them with confidence, and keep them from drifting. 

**Design drafts** — Design output is a **front-end page**: AI generation is mature, the toolchain is rich, there's no third-party lock-in, and it doubles as a shared language between people (the UI in your production code does not have to be front-end).



## Core Features

- **App management** — App list, plus conventions, layouts, paths, and asset installation.
- **Canvas management** — Canvas list, with AI authoring.
- **Asset management** — Style assets, layout assets, and AI-assisted filtering.
- **Mock data** — Built-in fake data to fill drafts.
- **IDE Skill** — `/wn-design-prd`, turn a PRD / design requirement into App-compliant Canvases from the IDE.
