Getting Started / Quick start

Quick start

Get a themed, responsive interface running in under five minutes using the DesignHub token system.

Installation

Install the package with your preferred package manager. The library ships with zero runtime dependencies and works with any framework.

# npm
npm install @designhub/tokens

Once installed, import the base stylesheet once at the root of your application.

Configuration

Themes are driven entirely by a single data-theme attribute on the root element. Define your token values for each theme and the rest of the system follows.

const config = {
  theme: 'light',
  primary: '#1a56db',
  radius: '10px'
}
Every component references semantic roles like surface and text, never raw colors — so a single switch retheme the whole app.

Usage

Compose your interface from the provided primitives. Layout, spacing and color all resolve from the active theme automatically, and dark mode requires no extra work.

You can override any token at any level of the tree, which makes scoped theming — like a dark sidebar inside a light app — straightforward.
