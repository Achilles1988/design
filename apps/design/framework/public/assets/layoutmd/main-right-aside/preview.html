Onboarding experience specification

ApprovedLast edited 2 hours ago·8 min read

This document defines the end-to-end onboarding flow for new users, from first sign-in through activation. The goal is to reduce time-to-value and improve the 7-day activation rate.

Objective: Lift 7-day activation from 41% to 55% by shortening the setup path to three essential steps.

1. Entry points

Users arrive from three primary channels: organic sign-up, invite links, and marketplace installs. Each entry point must resolve to the same canonical onboarding state machine to keep analytics consistent.

Flow diagram · onboarding state machine

2. Guided setup

The guided setup consists of three steps — profile, workspace, and integrations. Steps are skippable but nudged. Progress is persisted server-side so users can resume across devices.

Empty states throughout the product should point back to any incomplete setup step, keeping the activation loop visible without being intrusive.

3. Success criteria

Activation is defined as completing the workspace step plus one meaningful action within seven days. Instrumentation lives in the analytics pipeline under the onboarding.* event namespace.

We will run a two-week experiment at 10% traffic before a full rollout, gating on activation lift and no regression in day-1 retention.
