Tabs

The <Tabs> component lets you organize content into switchable panels within a single container.

First tab Second tab Third tab
Geist Mono · jsx
<Tabs defaultIndex={0}>
  <Tab title="First tab">
    // panel content
  </Tab>
</Tabs>

Properties

defaultIndex number

Zero-based index of the tab that is open on first render.

items Tab[] Required

Array of tab definitions rendered as the switchable panels.
