Capturing your first event

Install the PostHog JavaScript snippet and call posthog.capture() to send a custom event. Read the full installation guide for framework-specific setups.

// initialize PostHog import posthog from 'posthog-js' posthog.init('phc_your_key', { api_host: 'https://us.i.posthog.com', }) // capture a custom event posthog.capture('signup_completed', { plan: 'free', })
💡
Tip: Events are batched and flushed automatically — no need to await each capture call.
✅
Success: Once installed, your first events appear in the activity feed within seconds.
📚
Note: Autocapture records clicks and pageviews without any extra instrumentation.
