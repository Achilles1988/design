What is OpenCode?

An open source coding agent that lives in your terminal. It loads the right language servers, edits across your repo, and works with whatever model you bring.

FAQ
+Is OpenCode really free?
Yes — the agent is open source under a permissive license. OpenCode Zen adds hosted model routing.
+Which models can I use?
Any — Claude, GPT, Gemini, or a local model. Bring your own key or route through Zen.
−Does it send my code anywhere?
No. Code stays local; only the prompts you approve are sent to the model you configure.
