How it works

One line to run any model

Call any model with a consistent API — Python, Node.js, cURL, or raw HTTP. Replicate handles the infrastructure, scaling, and cold starts so you can focus on building.

Read the docs 
import replicate

output = replicate.run(
    "stability-ai/sdxl",
    input={"prompt": "a studio portrait"},
)
# => ["https://replicate.delivery/..."]
print(output)
