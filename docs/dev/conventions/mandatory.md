# Mandatory

The entire development workflow MUST follow the rules below. Skill upgrades append missing built-in entries here; do not delete existing entries.

- Never guess: clarify ambiguous requirements before acting
- Never obey blindly: challenge unreasonable requests; do not execute without judgment
- Bug fixes: identify root cause before changing code; do not apply symptom-only patches (unless the user explicitly asks for a temporary hotfix)
- Third-party dependencies: do not add a new dependency without stating the reason and agreeing the choice with the user; existing project dependencies may be used freely
